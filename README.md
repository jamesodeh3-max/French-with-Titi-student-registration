# French with Titi - Student Registration

🇫🇷 A professional student registration and course management platform for French language classes.

## Overview

This project provides a modern, responsive registration form for "French with Titi," an online French language course platform offering three learning pathways:

- **Beginner Pathway** (A1 → A2) - ₦234,000 for 3 months
- **Intermediate Pathway** (B1 → B2) - ₦255,000 per 3-month term
- **Advanced Pathway** (C1 → C2) - ₦270,000 per 3-month term

## How to Use

1. Open `index.html` in a web browser
2. Review the course offerings and pricing
3. Complete the registration form with your details
4. Agree to the rules and regulations
5. Submit your registration

## Form Fields

- **Full Name** (required) - Student's complete name
- **Email Address** (required) - Contact email for confirmation
- **Course Pathway** (required) - Select from Beginner, Intermediate, or Advanced
- **TEF/TCF Preparation** (optional) - Choose exam prep if needed
- **Starting Level** (auto-filled) - Based on pathway selection
- **Target Level** (auto-filled) - Based on pathway selection
- **Agreement Checkbox** (required) - Confirm understanding of rules and non-refundable policy

## Customization

To customize this registration form:

1. Update course details in the price table (HTML)
2. Modify bank account information in the Payment Details section
3. Adjust pricing and duration in the course pathway options
4. Update the success message in the `handleSubmit()` JavaScript function
5. Modify colors in the CSS `<style>` section
